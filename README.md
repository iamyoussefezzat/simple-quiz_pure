🎯 Simple Quiz (Pure JavaScript)

A lightweight and straightforward quiz application built with plain JavaScript, HTML, and CSS — perfect for learning, testing knowledge, or integrating into other projects.




---

🧠 Overview

Simple Quiz is designed to offer an easy-to-use quiz experience without any frameworks.
With this tool you can:

Create and play quizzes comprised of questions.

See immediate feedback on answers (correct / incorrect).

View final score and optionally restart the quiz.

Easily extend or customize questions, styles, or logic.



---

🚀 Features

✅ Built using only vanilla JavaScript, HTML, and CSS — no dependencies.

⚡ Fast, responsive UI that works across modern browsers.

📝 Clear scoring and feedback mechanism at the end of the quiz.

🧩 Easy to customize: add/edit questions, adjust styling, or enhance logic.

📦 Self-contained: clone, open index.html, and you're ready.

🧮 How to Use / Customize

1. Open questions.js and add or modify question objects. Example structure:

{
  question: "What is the capital of France?",
  options: ["Paris", "Berlin", "Madrid", "London"],
  answer: 0
}


2. In script.js, you can adjust:

Number of questions shown.

Timer or time-based scoring (if you choose to add).

Feedback messages, UI styles, or animations.



3. Modify styles.css to change colours, fonts, layout to match your branding or theme.
